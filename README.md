# Misterios de Tudela

Casos de misterio jugables ambientados en la Tudela de verdad (Navarra). Caso 1: *El ahogado del puente*, octubre de 1485.

Se juega en el navegador, mejor desde el móvil: https://juanmartin1392-bit.github.io/misterios-tudela/

Proyecto personal sin ánimo de lucro. Crímenes y personajes inventados; calles, edificios y oficios, de la historia real.
